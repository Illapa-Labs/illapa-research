# Data and attribution

The AGPL of this repository covers the **code**, not the data. `descargar-datos` only fetches sources with a clear licence; every download is logged in `datos/MANIFIESTO.json`. Reviewed on 29 October 2026. This project does not own this data and does not guarantee it.

| Data | Source | Licence | Attribution |
|---|---|---|---|
| Rivers and departments | [Natural Earth](https://www.naturalearthdata.com) | Public domain | Not required |
| Rivers and ravines (Chaclacayo to Chosica) | [OpenStreetMap](https://www.openstreetmap.org/copyright), via Overpass | ODbL 1.0 | "© OpenStreetMap contributors". A published derived database must stay under ODbL |
| Historical daily rainfall | [Open-Meteo](https://open-meteo.com) | CC BY 4.0; the free API is non-commercial only | "Weather data by Open-Meteo.com" |

## Left out for now

- **SENAMHI** (warnings, stations, boundaries): no reuse licence is published. Written authorisation still needs to be requested from atencionalciudadano@senamhi.gob.pe.
- **INEI** (2017 Census): terms to be checked.
- **Elevation models for hydrology**: check each licence before use.

## Publishing derived data

Before uploading a dataset to Hugging Face or elsewhere, confirm that every source in it allows redistribution, and publish it with its licence and attribution.
